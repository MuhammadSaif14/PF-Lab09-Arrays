# PF Lab 09 – Arrays

This repository contains my solutions for **Lab#09** of the course **CL-1002 Programming Fundamentals** (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in **C**. Array sizes are defined with `#define`, `for` loops are used to read, process, and print arrays, and no index goes outside `0` to `SIZE-1`. Programs are compiled with `-Wall` and are free of warnings.

## Programs Included
1. **The Last-Over Thriller** – stores runs of 6 overs, finds total runs, run rate, and the best over, and checks if the target of 60 was reached.
2. **The Hostel Lost-and-Found** – uses linear search to list every locker holding an item, and counts empty lockers.
3. **Fair Judging at the Talent Show** – drops the highest and lowest of 7 scores and finds the final average, and finds the first perfect 10.
4. **The Security Guard Roster** – shifts a weekly roster forward by k days with wrap-around using `%`, and searches for a guard's new duty day.
5. **Forged Tickets at the Concert** (nested loop) – detects duplicate ticket numbers and counts genuine and forged entries.
6. **Position Holders of Section B** (nested loop) – sorts students by marks (highest first) while keeping roll numbers matched, and prints the top 3.

## How to Run
```bash
gcc -Wall filename.c -o output
./output
```
